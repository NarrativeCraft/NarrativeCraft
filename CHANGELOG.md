# Changelog

## [2.0.0]

### Features
- Stories can be started or stopped through the API
- Stories can now be advanced with a left click
- The HUD hides automatically when the player is on a camera
- A pause screen is now available during stories
- Sprint and camera control are disabled outside of gameplay sequences
- The scene menu opens automatically when a session is configured
- Clear error messages when a story script is missing required tags
- Secured server packet

### Fixes
- Stories are correctly marked as finished when completed
- Pause screen no longer appears for other players on the server
- Character skin now loads correctly when a character spawns
- Duplicate character names are now prevented
- Adding template characters on Fabric no longer crashes the game
- HUD display issue on Fabric has been resolved
- Renaming entries now correctly moves their associated data
- Animations are properly removed on the client when deleted from the server
- Recording now stops correctly
- Subscene names containing spaces are now handled properly
- Weather and time changes in stories now work correctly
- Returning to the story list no longer closes the screen
- Interaction zones only trigger when entering, not when leaving
- Interaction points only respond when directly aimed at
- Interaction folders are now created properly

### Misc
- Minor documentation fixes
